\subsection{Error as a Function of the Bending Angle}
Fig.~S7 relates the tip position error on the test sets to the bending angle. For the single-section arm, the error decreases with bending (Spearman $\rho = -0.22$, $p < 0.001$ for position; $\rho = -0.14$, $p = 0.001$ for orientation). For the multi-section arm, the tip errors show no clear dependence on the bending angle of the corresponding section ($|\rho| \le 0.06$).
